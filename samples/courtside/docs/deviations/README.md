# Deviations folder

One file per deviation, named `D<nnn>-<kebab-title>.md`. The index is [../DEVIATIONS.md](../DEVIATIONS.md).

A deviation file has a title, the date and milestone, the spec it amends, what the code touches, and a status (`Open`, or `Resolved → spec updated` once the spec text matches the code). Then four sections: *Spec says*, *Implementation does*, *Why* and *Consequences*. Add a `> **DEVIATION:** see [D007](…)` note under the spec section it amends, in the same change.
