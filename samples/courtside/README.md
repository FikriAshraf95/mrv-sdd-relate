# Courtside

Court bookings for a community sports hall: members reserve a badminton or tennis court, pay for it, and queue for a slot that is taken. Front-desk staff can override the rules.

This is an **invented sample project** for SDD Graph. It is built spec-first: `docs/specs` holds six specs plus an overview, `docs/milestones` eight milestones, and [the deviation log](docs/DEVIATIONS.md) the six places where the code departs from a spec. The code under `src/` is a small placeholder tree, grouped by feature.

Start with the table every story touches: `sdd impact bookings`.
