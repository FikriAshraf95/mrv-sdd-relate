# Export diagrams and the CLAUDE.md status block

> **For:** anyone who wants graph pictures in their README, or a CLAUDE.md that always shows where the project stands.

## Mermaid diagrams

```bash
sdd export --mermaid schema                       # every label and relationship type, with counts
sdd export --mermaid milestone:M05a               # a milestone, its tasks, sections read, deviations
sdd export --mermaid impact:bookings              # an impact result as a graph
sdd export --mermaid explain:src/booking/overlap.py
sdd export --mermaid lineage:SPEC-03#4            # deviations amending a section → tasks → files
sdd export --mermaid feature:booking              # a feature → specs, files, tables
sdd export --mermaid schema --out docs/schema.mmd
```

The output is a Mermaid `flowchart LR`. Paste it into a fenced ` ```mermaid ` block in any Markdown file and GitHub renders it. The output is deterministic (same graph, same text), so it diffs cleanly.

You can also pass a read-only Cypher query. Any argument starting with `MATCH`, `OPTIONAL MATCH`, `WITH`, `UNWIND`, `CALL` or `RETURN` is treated as Cypher and runs through the query guard:

```bash
sdd export --mermaid "MATCH (m:Milestone)-[:INCLUDES]->(t:Task) WHERE m.id = 'M05a' RETURN m, t"
```

Every returned node becomes a node; a row with `source` and `target` columns becomes an edge. At most 60 nodes are drawn (the last line says `%% truncated N nodes` beyond that).

The same diagrams are available over HTTP: `GET /api/mermaid?preset=impact%3Abookings`.

## The CLAUDE.md status block

Add two marker lines to your CLAUDE.md, where the status should go:

```markdown
## Status

<!-- sdd:status -->
<!-- /sdd:status -->
```

Then run:

```bash
sdd export --claude-status
```

It replaces whatever is between the markers with a generated block, and touches nothing outside them:

```markdown
<!-- sdd:status -->
_Generated by `sdd export --claude-status`; edit outside the markers._
- **Done:** M01 Skeleton and members (2026-09-18) · M02 Courts and schema (2026-09-30) · …
- **Next:** [M05a Waitlist](docs/milestones/M05a-waitlist.md) (2/4 tasks open). Read first: SPEC-02 waitlist_entries · SPEC-05 §1 · SPEC-05 §2 · SPEC-05 §4
- **Open deviations:** D003 Cancelled bookings are kept with cancelled_at (M03b) · …
- **Active claims:** none
<!-- /sdd:status -->
```

- It has no timestamps, so a second run with nothing changed writes nothing and prints `already up to date`.
- CRLF files stay CRLF.
- Without the file or the markers, it fails with `invalid_input` (exit 2) and prints the two lines to add.

Run it after `complete_milestone`, or in a pre-commit hook, so every new agent session sees the current state in CLAUDE.md without any tool call.
